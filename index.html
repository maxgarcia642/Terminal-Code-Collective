Multi-Language Execution Support

This terminal supports 100+ programming languages through multiple execution APIs with smart fallback routing:

Note: Your code must be applicable with a batch input execution model since the code runs on remote execution services where real-time interactive input isn't possible, all inputs are collected upfront from stdin, and are even retrieved sequentially using a next_input() function.

Execution Providers:

  • Piston API (Primary) - 80+ languages including esoterics: Brainfuck, LOLCODE, Rockstar, Befunge-93, Cow, Emojicode, Vyxal
  • Judge0 CE - 60+ languages: C/C++, Java, Python, Go, Rust, Fortran, Assembly (NASM), Pascal, Ada
  • Glot.io - Functional/esoteric: Mercury, Idris, Nix, OCaml, Raku, ATS, Elm, Guile

Popular Languages:

Python, JavaScript, TypeScript, Java, C, C++, C#, Go, Rust, Ruby, PHP, Swift, Kotlin, Scala, R, Perl, Lua, Bash, Haskell, Elixir, Clojure, F#, Dart, Julia, Nim, Crystal, OCaml, Pascal, Fortran, COBOL, D, Groovy, Lisp, Prolog, Erlang, and many more!

How to Use:

  1. Upload a file OR paste/type code directly
  2. The system auto-detects your language
  3. Click EXECUTE to run your code
  4. The smart router tries multiple APIs for best results

Note: Type your input in the input box at the bottom of the output terminal before clicking Execute, or use the sample code which has interactive menus built-in. All inputs are sent to the program when executed.
